05 · ROADMAP

5일 구현
로드맵

강태오 개발자가 산출한 실제 공수 견적. P0 필수 항목 3일, P1 포함 시 5일.

01
Day 1 · 디자인 시스템 토대
index.css 교체 + Tailwind config 확장 + 공용 컴포넌트
▼
  • • 09:00 src/index.css 완전 교체 (CSS 변수 모두 Forest Olive로)
  • • 11:00 tailwind.config.ts 확장 (신규 토큰, 폰트 패밀리, 섀도우)
  • • 14:00 shadcn Button, Card, Input, Badge 리스타일
  • • 16:00 폰트 로드 최적화 (Google Fonts text= 섭셋팅)
  • • 17:00 index.html PWA theme-color, OG 메타 업데이트
02
Day 2 · 온보딩 + 홈
6단계 → 3단계 + Home 재구성 + Bottom Nav
▼
  • • Onboarding 3-step 리팩토링 (skin_type / concerns+sensitivity / age+routines)
  • • Supabase profiles 테이블 스키마 적용 (8 필드)
  • • Home 화면 재구성 (URL hero 입력 + 추천 그리드 + 히스토리)
  • • Bottom Navigation 재설계 (5탭 + 센터 floating CTA)
03
Day 3 · Analyzing + Result
시그니처 스캔 모션 + 매치율 중심 재배치
▼
  • • Analyzing 화면 신설 (스캔 라인 + 실시간 성분 pop-up + 2.4초 최소 보장)
  • • Grok Edge Function 통합 + 매치율 산출 로직 v1
  • • Product Detail 매치율 중심 재배치
  • • 카피 일괄 교체 (지적 간결체 톤 적용)
04
Day 4 · 다크모드 + 공유
Profile 설정 + html2canvas 공유 + Empty States
▼
  • • Dark mode 전체 토큰 적용 + 테마 스위치 (next-themes 활용)
  • • Profile / Settings 페이지 신설
  • • 공유 이미지 생성 (html2canvas + 카카오톡 공유)
  • • Empty States · Error States 전체 일러스트 적용
05
Day 5 · QA + 배포
Analytics + E2E + Lighthouse + PWA 캐시
▼
  • • Supabase events 테이블 + useTrack() Hook 심기
  • • Playwright E2E 기본 플로우 3개
  • • axe-core a11y 자동 검증 + 수정
  • • PWA 버전업 + Service Worker 캐시 갱신
  • • Vercel 프리뷰 → 프로덕션 배포

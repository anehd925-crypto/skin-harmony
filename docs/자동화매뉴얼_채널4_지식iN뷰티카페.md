# 채널 4. 네이버 지식iN + 뷰티 카페 — 반자동화 세팅 매뉴얼

> AI가 답변 초안을 만들고, 사람이 복붙해서 게시하는 방식.  
> 답변 1개 게시에 5분 이하. 채택된 답변은 수년간 검색에 노출됩니다.

**자동화 수준**: ⭐⭐☆☆☆ 부분 자동 (AI 초안 생성)  
**초기 세팅 소요 시간**: 약 30분 (1회만)  
**이후 일일 운영 시간**: 15~20분/일

---

## 전체 흐름 한눈에 보기

```
매일 10~15분
  ↓
① 지식iN에서 성분 관련 최신 질문 5~10개 검색 (3분)
  ↓
② 답변하기 좋은 질문 2~3개 선택 (1분)
  ↓
③ ChatGPT에 질문 붙여넣기 → AI 초안 자동 생성 (1~2분/개)
  ↓
④ 초안 간단 검토 → 지식iN에 복붙 게시 (2~3분/개)
  ↓
  결과: 하루 2~3개 답변 = 월 60개 = 채택 시 장기 검색 노출
```

## STEP 1. 네이버 지식iN 계정 설정

### 1-1. 네이버 계정 준비

> BeautyLens 브랜드 계정을 별도로 만드는 것을 권장합니다.  
> 기존 개인 계정으로 해도 되지만 브랜드 계정이 신뢰도에 유리합니다.

1. `nid.naver.com` → "회원가입"
2. 아이디: `BeautyLens` 또는 `beautylens_official`
3. 가입 후 프로필 설정:
   - 닉네임: `BeautyLens 뷰티렌즈`
   - 프로필 사진: BeautyLens 로고
   - 소개: `AI 전성분 분석 앱 BeautyLens 운영팀입니다. 피부 성분 관련 질문에 답변드립니다.`

### 1-2. 지식iN 전문가 등급 목표

지식iN은 답변 품질에 따라 등급이 올라갑니다.  
등급이 높을수록 답변이 상단에 노출되는 경향이 있습니다.

| 등급 | 조건 | 효과 |
|------|------|------|
| 씨앗 | 신규 | 기본 노출 |
| 새싹 | 채택 10개 이상 | 노출 향상 |
| 잎사귀 | 채택 50개 이상 | 우선 노출 |
| 나무 | 채택 200개 이상 | 전문가 배지 노출 |

아래 링크를 브라우저 북마크 폴더 "BeautyLens 마케팅"에 저장해두세요.  
매일 클릭하면 최신 질문을 바로 볼 수 있습니다.

```

피부 타입 질문:
https://kin.naver.com/search/list.naver?query=피부+성분+추천&section=kin

전성분 질문:
https://kin.naver.com/search/list.naver?query=전성분+분석

여드름 성분 질문:
https://kin.naver.com/search/list.naver?query=여드름+화장품+성분

임신 성분 질문:
https://kin.naver.com/search/list.naver?query=임신+화장품+성분

건성 피부 성분:
https://kin.naver.com/search/list.naver?query=건성피부+성분

루틴 성분 충돌:
https://kin.naver.com/search/list.naver?query=스킨케어+성분+충돌
```

### 매일 검색할 키워드 목록 (지식iN 검색창에 직접 입력)

```
우선순위 높음 (매일 확인):
1. 화장품 성분
2. 전성분
3. 피부 성분 추천
4. 건성 피부 화장품

우선순위 중간 (격일 확인):
5. 임신 화장품 성분
6. 여드름 성분
7. 민감성 피부 성분
8. 레티놀
9. 나이아신아마이드
10. 성분 충돌 루틴
```

## STEP 3. AI 답변 초안 생성 — ChatGPT 프롬프트 세트

### 3-1. 범용 성분 질문 답변 프롬프트

> 가장 많이 쓰는 프롬프트입니다. 한 번 저장해두고 계속 재사용하세요.

```
당신은 뷰티·스킨케어 성분 전문가입니다.

아래 네이버 지식iN 질문에 대해 답변을 작성해주세요.

[답변 작성 규칙]
1. 질문에 정확하고 실용적으로 답변 (7~12줄)
2. 번호 리스트 또는 소제목으로 읽기 쉽게 구성
3. 전문 용어는 쉬운 말로 설명
4. 피부 타입별 차이가 있다면 언급
5. 마지막 줄: "성분표 분석이 번거로우시다면, BeautyLens라는 무료 앱에서 제품 URL이나 사진으로 내 피부 기준 분석을 받아볼 수 있습니다."
6. 직접적인 홍보 문구 금지 ("다운로드하세요" 금지)
7. 친근하고 도움이 되는 말투

[질문]
{아래에 지식iN 질문 전체 텍스트를 붙여넣어 주세요}

답변만 출력해주세요. 부가 설명 없이.
```

---

### 3-2. 성분 충돌 질문 전용 프롬프트

```
당신은 스킨케어 성분 궁합 전문가입니다.

아래 성분 관련 질문에 답변해주세요.

[특별 지침]
- 성분 충돌/궁합 관련 질문이면 아래 형식 사용:
  ① 이 조합이 문제인 이유 (1~2문장)
  ② 올바른 사용 방법 또는 대안
  ③ 추가 주의사항 (있는 경우)
- 마지막 줄: "내 루틴 제품들의 성분 궁합이 걱정된다면, BeautyLens 앱의 루틴 분석 기능에서 한 번에 확인할 수 있습니다."

[질문]
{질문 텍스트 붙여넣기}
```

### 3-3. 임신·수유 중 성분 질문 전용 프롬프트

> 이 주제는 검색량이 많고 경쟁이 적어 채택률이 높습니다.

```
당신은 임신·수유 중 화장품 성분 안전성 전문가입니다.

아래 질문에 답변해주세요.

[특별 지침]
- 반드시 "의사 또는 전문가와 상담을 권장드립니다" 문구 포함
- 피해야 할 성분과 사용 가능한 성분을 명확히 구분
- 불안하게 만드는 표현 지양, 실용적 정보 제공 중심
- 마지막 줄: "임신·수유 중 사용 가능한 성분인지 BeautyLens에서 제품 성분표를 분석해볼 수 있습니다. 단, 최종 판단은 의사와 상담을 권장드립니다."

[질문]
{질문 텍스트 붙여넣기}
```

### 3-4. 올리브영 제품 성분 질문 전용 프롬프트

```
당신은 화장품 성분 분석 전문가입니다.

아래 올리브영 또는 특정 제품 성분 관련 질문에 답변해주세요.

[특별 지침]
- 해당 제품의 주요 성분(나이아신아마이드, 세라마이드, 레티놀 등)을 중심으로 분석
- 질문자의 피부 타입에 맞는지 판단 (언급된 경우)
- 구체적인 성분명 영어 표기 병기
- 마지막 줄: "올리브영 제품 URL을 BeautyLens에 붙여넣으면 성분을 자동으로 분석하고 내 피부 적합도를 알려줍니다."

[질문]
{질문 텍스트 붙여넣기}
```

## STEP 4. 북마크 도구 세팅 (크롬 기준)

### 4-1. 브라우저 북마크 폴더 만들기

1. Chrome 브라우저 열기
2. 북마크 바 빈 곳에서 마우스 오른쪽 클릭
3. "폴더 추가" → 이름: `BeautyLens 마케팅`
4. 아래 링크들을 이 폴더에 북마크 추가:
   - 지식iN 검색 링크들 (STEP 2의 목록)
   - ChatGPT (`chat.openai.com`)
   - Supabase 대시보드 (`supabase.com`)
   - BeautyLens X 계정 Analytics

### 4-2. ChatGPT에 프롬프트 저장하기

> ChatGPT "GPTs" 또는 "Custom Instructions"에 저장하면 매번 입력 불필요

1. ChatGPT 접속 → 좌측 하단 프로필 → "Custom Instructions"
2. "What would you like ChatGPT to know about you?" 란에:
   ```
   나는 BeautyLens라는 AI 스킨케어 성분 분석 앱을 운영합니다.
   뷰티 성분 관련 지식iN 답변 작성에 도움이 필요합니다.
   항상 한국어로 답변하고, 마지막 줄에 BeautyLens 앱을 자연스럽게 언급해주세요.
   ```
3. "How would you like ChatGPT to respond?" 란에:
   ```
   - 항상 한국어로 작성
   - 지식iN 답변 형식: 7~12줄, 번호 리스트 활용
   - 마지막 줄에만 BeautyLens 앱 언급 (1문장)
   - 직접 광고 표현 금지
   - 전문적이지만 친근한 말투
   ```

## STEP 5. 뷰티 카페 참여 전략

### 공략 커뮤니티 목록

| 커뮤니티 | 특징 | 접근 방법 |
|---------|------|---------|
| **파우더룸** (`powderroom.net`) | 국내 최대 뷰티 커뮤니티, 성분 글 많음 | 회원가입 후 성분 관련 글에 댓글 |
| **네이버 카페 뷰스타** | 뷰티 성분 관심층 집중 | 네이버 카페 검색 → 가입 후 활동 |
| **더쿠 뷰티 게시판** (`theqoo.net`) | 20~30대 여성 중심 | 성분 관련 게시글에 정보 댓글 |
| **디시인사이드 화장품 갤러리** | 성분 덕후 집중 | 정보성 글 직접 게시 |

### 카페 활동 원칙

```
✅ 해야 할 것:
- 성분 관련 질문 글에 정확한 정보로 답변
- "BeautyLens로 분석해봤는데..." 형식의 실제 사용 후기 공유
- 올리브영 신상 성분을 분석해서 정보 제공

❌ 하지 말아야 할 것:
- 홍보글 직접 게시 (카페 규정 위반, 강퇴 위험)
- 여러 계정으로 자작 활동
- 허위·과장 정보 제공
- 앱만 강조하는 광고성 댓글
```

### 파우더룸 활동 방법 (상세)

1. `powderroom.net` 접속 → 회원가입
2. 상단 메뉴 "성분 이야기" 또는 "스킨케어" 게시판 클릭
3. 성분 관련 질문 글 또는 최신 토론 글 탐색
4. 자신의 BeautyLens 분석 경험을 자연스럽게 공유하는 댓글 작성

**댓글 예시:**
```
저도 같은 고민이 있었는데요, BeautyLens라는 앱으로 분석해봤더니
레티놀 함량이 0.1% 이하라 건성 피부에도 괜찮다는 결과가 나왔어요.
올리브영 URL 붙여넣으면 바로 분석되더라고요.
참고로 저는 건성+민감성인데 적합도 78점 나왔어요.
```

## STEP 6. 일일 운영 루틴 (15~20분)

아래 순서대로 매일 진행합니다. 시간이 없는 날은 ①②만 해도 됩니다.

```
① 지식iN 키워드 검색 → 답변할 질문 2~3개 선택 (3분)
   → 북마크한 검색 링크 3~4개 열기
   → 미답변 질문 중 답변 가능한 것 선택

② ChatGPT에 질문 붙여넣기 → 초안 생성 → 지식iN에 복붙 (5~8분)
   → 프롬프트 복붙
   → 질문 내용 아래에 추가
   → ChatGPT 답변 복사 → 지식iN 답변창에 붙여넣기
   → 내용 간단히 확인 후 "답변 등록"

③ (선택) 파우더룸 또는 더쿠 방문 → 관련 글에 댓글 (5분)
   → 북마크 링크 클릭
   → 최신 글 중 성분 관련 글에 정보 댓글

④ (주 1회, 금요일) 이번 주 채택 답변 수 확인 (2분)
   → 지식iN 프로필 → "내 활동" → "채택 답변" 수 확인
   → KPI 스프레드시트에 기록
```

## STEP 8. 답변 채택률을 높이는 팁

| 팁 | 상세 설명 |
|----|---------|
| **빠른 답변** | 질문 게시 후 수 분 내에 답변 달면 채택률 상승 |
| **구체적 수치** | "레티놀 0.1% 이하는 일반적으로 안전" 등 수치 포함 |
| **이미지 첨부** | 답변에 성분 정보 이미지 첨부 시 채택률 20~30% 상승 (지식iN 지원) |
| **감사 댓글 대응** | 질문자가 "감사합니다" 댓글 달면 추가 답변으로 채택 유도 |
| **미채택 질문 팔로업** | 3일 후 채택 안 된 답변에 추가 정보 댓글 |

| 규칙 | 이유 |

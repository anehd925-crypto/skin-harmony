# 채널 3. 앱 내 바이럴 루프 — 공유 기능 구현 매뉴얼

> 사용자가 분석 결과를 카카오톡·인스타그램 등으로 공유할 때 자동으로 앱이 노출됩니다.  
> 한 번 구현하면 이후 추가 작업 없이 자동으로 작동합니다.

**자동화 수준**: ⭐⭐⭐⭐⭐ 완전 자동 (개발 후)  
**초기 개발 소요 시간**: 약 2~3시간  
**이후 운영 시간**: 0시간 (자동)

---

## 전체 흐름 한눈에 보기

```
사용자가 성분 분석 완료
  ↓
"결과 공유하기" 버튼 클릭 (기존 버튼 업그레이드)
  ↓
브라우저가 분석 결과를 카드 이미지로 자동 생성
  ↓
카카오톡 / 인스타그램 스토리 / X 공유 선택
  ↓
공유된 이미지를 본 친구가 링크 클릭
  ↓
BeautyLens 앱으로 자동 유입 (UTM 추적)
  ↓
신규 회원 가입 → 바이럴 루프 반복
```

```typescript
// 현재: 텍스트만 공유 (IngredientAnalysis.tsx 101~134번 줄)
const handleShare = async () => {
  const text = `[BeautyLens 전성분 분석 결과]\n제품명: ...`;
  if (navigator.share) {
    await navigator.share({ text }); // 텍스트만 공유
  }
};
```

**개선 목표**: 텍스트 공유 → **시각적 카드 이미지 공유**로 업그레이드

## STEP 1. 공유 카드 컴포넌트 파일 생성

**파일 경로**: `src/components/ShareResultCard.tsx` (새 파일 생성)

**전체 코드:**

```tsx
import { useRef, useCallback } from "react";
import { Button } from "@/components/ui/button";
import { Share2, Download } from "lucide-react";

interface ShareResultCardProps {
  productName: string;
  productBrand?: string;
  skinFitScore?: number;
  skinFitLabel?: string;
  overallGrade: "good" | "moderate" | "bad";
  safeCount: number;
  cautionCount: number;
  dangerCount: number;
  skinType?: string;
}

// 등급 텍스트와 색상 변환
function getGradeInfo(grade: string) {
  switch (grade) {
    case "good":    return { label: "안전",  color: "#22C55E" };
    case "moderate":return { label: "보통",  color: "#F59E0B" };
    case "bad":     return { label: "주의",  color: "#EF4444" };
    default:        return { label: "분석됨", color: "#6B7280" };
  }
}

// 피부 적합도 점수 색상
function getScoreColor(score: number) {
  if (score >= 70) return "#22C55E";
  if (score >= 40) return "#F59E0B";
  return "#EF4444";
}

export function ShareResultCard({
  productName,
  productBrand,
  skinFitScore,
  skinFitLabel,
  overallGrade,
  safeCount,
  cautionCount,
  dangerCount,
  skinType,
}: ShareResultCardProps) {
  const canvasRef = useRef<HTMLCanvasElement>(null);

  // 캔버스에 공유 이미지 그리기
  const drawCard = useCallback((): Promise<Blob> => {
    return new Promise((resolve, reject) => {
      const canvas = canvasRef.current;
      if (!canvas) return reject(new Error("canvas not found"));

      const ctx = canvas.getContext("2d");
      if (!ctx) return reject(new Error("canvas context not found"));

      // 캔버스 크기 (정사각형 — 인스타그램 호환)
      const W = 600;
      const H = 600;
      canvas.width  = W;
      canvas.height = H;

      const gradeInfo = getGradeInfo(overallGrade);
      const scoreColor = skinFitScore != null ? getScoreColor(skinFitScore) : "#6B7280";

      // ── 배경 ──
      ctx.fillStyle = "#FAFAF8";
      ctx.fillRect(0, 0, W, H);

      // ── 상단 헤더 바 ──
      ctx.fillStyle = "#1A1A1A";
      ctx.fillRect(0, 0, W, 72);

      ctx.fillStyle = "#FFFFFF";
      ctx.font = "bold 20px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
      ctx.textAlign = "center";
      ctx.fillText("🔬 BeautyLens 전성분 분석 결과", W / 2, 44);

      // ── 제품명 ──
      const displayName = productName.length > 22
        ? productName.slice(0, 22) + "…"
        : productName;
      ctx.fillStyle = "#1A1A1A";
      ctx.font = "bold 22px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
      ctx.textAlign = "center";
      ctx.fillText(displayName, W / 2, 128);

      // 브랜드명
      if (productBrand) {
        ctx.fillStyle = "#9CA3AF";
        ctx.font = "16px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
        ctx.fillText(productBrand, W / 2, 154);
      }

      // ── 종합 등급 뱃지 ──
      const badgeY = productBrand ? 190 : 170;
      ctx.fillStyle = gradeInfo.color + "22"; // 반투명 배경
      roundRect(ctx, W / 2 - 60, badgeY, 120, 36, 18);
      ctx.fillStyle = gradeInfo.color;
      ctx.font = "bold 18px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
      ctx.textAlign = "center";
      ctx.fillText(`종합 등급: ${gradeInfo.label}`, W / 2, badgeY + 24);

      // ── 피부 적합도 ──
      if (skinFitScore != null) {
        const scoreY = badgeY + 70;
        ctx.fillStyle = scoreColor;
        ctx.font = "bold 56px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
        ctx.textAlign = "center";
        ctx.fillText(`${skinFitScore}점`, W / 2, scoreY + 50);

        ctx.fillStyle = "#6B7280";
        ctx.font = "15px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
        ctx.fillText(
          `내 피부 적합도${skinType ? ` (${skinType})` : ""}`,
          W / 2,
          scoreY + 76
        );

        if (skinFitLabel) {
          ctx.fillStyle = scoreColor;
          ctx.font = "bold 14px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
          ctx.fillText(`[ ${skinFitLabel} ]`, W / 2, scoreY + 98);
        }
      }

      // ── 성분 카운트 박스 ──
      const countY = 400;
      const boxW = 160;
      const boxes = [
        { label: "✅ 안전", count: safeCount,   color: "#22C55E", x: 60  },
        { label: "⚠️ 주의", count: cautionCount, color: "#F59E0B", x: 220 },
        { label: "❌ 위험", count: dangerCount,  color: "#EF4444", x: 380 },
      ];

      for (const box of boxes) {
        ctx.fillStyle = box.color + "18";
        roundRect(ctx, box.x, countY, boxW, 72, 12);

        ctx.fillStyle = box.color;
        ctx.font = "bold 28px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
        ctx.textAlign = "center";
        ctx.fillText(`${box.count}개`, box.x + boxW / 2, countY + 38);

        ctx.fillStyle = "#6B7280";
        ctx.font = "13px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
        ctx.fillText(box.label, box.x + boxW / 2, countY + 62);
      }

      // ── 하단 CTA ──
      ctx.fillStyle = "#F0EDE8";
      ctx.fillRect(0, 504, W, 96);

      ctx.fillStyle = "#374151";
      ctx.font = "15px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
      ctx.textAlign = "center";
      ctx.fillText("내 피부에 맞는 화장품 성분, 무료로 분석해보세요", W / 2, 538);

      ctx.fillStyle = "#7C3AED";
      ctx.font = "bold 17px 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif";
      ctx.fillText("BeautyLens (beautylens.app) →", W / 2, 572);

      // Blob으로 변환
      canvas.toBlob(
        (blob) => (blob ? resolve(blob) : reject(new Error("blob 생성 실패"))),
        "image/png"
      );
    });
  }, [productName, productBrand, skinFitScore, skinFitLabel, overallGrade, safeCount, cautionCount, dangerCount, skinType]);

  // 공유 버튼 클릭 핸들러
  const handleShare = async () => {
    try {
      const blob = await drawCard();
      const file = new File([blob], "beautylens-analysis.png", { type: "image/png" });
      const shareUrl = `https://beautylens.app?utm_source=share&utm_medium=card&utm_campaign=analysis`;

      // Web Share API (모바일에서 카카오·인스타 등으로 직접 공유 가능)
      if (navigator.canShare && navigator.canShare({ files: [file] })) {
        await navigator.share({
          title: "BeautyLens 성분 분석 결과",
          text: `${productName} 성분 분석 | ${shareUrl}`,
          files: [file],
        });
      } else if (navigator.share) {
        // 파일 공유 미지원 시 URL만 공유
        await navigator.share({
          title: "BeautyLens 성분 분석 결과",
          text: `${productName} 성분 분석 결과를 확인해보세요!`,
          url: shareUrl,
        });
      } else {
        // 데스크탑: 이미지 파일 다운로드
        const url = URL.createObjectURL(blob);
        const a = document.createElement("a");
        a.href = url;
        a.download = "beautylens-analysis.png";
        a.click();
        URL.revokeObjectURL(url);
      }
    } catch (err) {
      // 사용자가 공유 취소한 경우 무시
      console.log("공유 취소 또는 오류:", err);
    }
  };

  // 이미지 저장만 하는 핸들러 (선택적 추가 버튼)
  const handleDownload = async () => {
    try {
      const blob = await drawCard();
      const url = URL.createObjectURL(blob);
      const a = document.createElement("a");
      a.href = url;
      a.download = "beautylens-analysis.png";
      a.click();
      URL.revokeObjectURL(url);
    } catch (err) {
      console.error("이미지 저장 실패:", err);
    }
  };

  return (
    <>
      {/* 숨겨진 캔버스 (이미지 생성용) */}
      <canvas ref={canvasRef} className="hidden" />

      {/* 공유 버튼 UI */}
      <div className="flex gap-2 mt-3">
        <Button
          variant="outline"
          size="sm"
          onClick={handleShare}
          className="flex items-center gap-1.5 flex-1 border-primary/30 text-primary hover:bg-primary/5"
        >
          <Share2 className="w-3.5 h-3.5" />
          결과 공유하기
        </Button>
        <Button
          variant="ghost"
          size="sm"
          onClick={handleDownload}
          className="flex items-center gap-1.5 text-muted-foreground"
        >
          <Download className="w-3.5 h-3.5" />
          저장
        </Button>
      </div>
    </>
  );
}

// 모서리 둥근 사각형 그리기 헬퍼
function roundRect(
  ctx: CanvasRenderingContext2D,
  x: number, y: number,
  width: number, height: number,
  radius: number
) {
  ctx.beginPath();
  ctx.moveTo(x + radius, y);
  ctx.lineTo(x + width - radius, y);
  ctx.quadraticCurveTo(x + width, y, x + width, y + radius);
  ctx.lineTo(x + width, y + height - radius);
  ctx.quadraticCurveTo(x + width, y + height, x + width - radius, y + height);
  ctx.lineTo(x + radius, y + height);
  ctx.quadraticCurveTo(x, y + height, x, y + height - radius);
  ctx.lineTo(x, y + radius);
  ctx.quadraticCurveTo(x, y, x + radius, y);
  ctx.closePath();
  ctx.fill();
}
```

## STEP 3. 공유 추적용 Supabase DB 테이블 생성

> 얼마나 많이 공유되었는지, 공유 후 얼마나 유입됐는지 추적합니다.

Supabase SQL Editor에서 실행:

```sql
-- 공유 이벤트 로그 테이블
CREATE TABLE IF NOT EXISTS share_events (
  id           BIGSERIAL PRIMARY KEY,
  user_id      UUID REFERENCES auth.users(id) ON DELETE SET NULL,
  event_type   TEXT NOT NULL,  -- 'share_click', 'download_click'
  product_name TEXT,
  skin_fit_score INTEGER,
  shared_at    TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_share_events_user    ON share_events(user_id);
CREATE INDEX IF NOT EXISTS idx_share_events_type    ON share_events(event_type);
CREATE INDEX IF NOT EXISTS idx_share_events_date    ON share_events(shared_at DESC);

-- Row Level Security (본인 데이터만 조회 가능)
ALTER TABLE share_events ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can insert own share events"
  ON share_events FOR INSERT
  WITH CHECK (auth.uid() = user_id OR user_id IS NULL);

SELECT '공유 이벤트 추적 테이블 생성 완료' AS result;
```

## STEP 6. 성과 확인 방법

### 공유 클릭률 확인 (Supabase)

```sql
-- 일별 공유 클릭 수
SELECT
  DATE(shared_at AT TIME ZONE 'Asia/Seoul') AS date,
  COUNT(*) AS share_count
FROM share_events
WHERE event_type = 'share_click'
GROUP BY 1
ORDER BY 1 DESC
LIMIT 30;

-- 분석 횟수 대비 공유 비율 (전환율)
SELECT
  total_analyses,
  total_shares,
  ROUND(total_shares::numeric / NULLIF(total_analyses, 0) * 100, 1) AS share_rate_pct
FROM (
  SELECT
    (SELECT COUNT(*) FROM analysis_history) AS total_analyses,
    (SELECT COUNT(*) FROM share_events WHERE event_type = 'share_click') AS total_shares
) t;
```

### UTM 유입 확인

Google Analytics를 사이트에 연결했다면  
**획득 → 트래픽 소스 → utm_campaign = analysis** 필터로 확인

Google Analytics 미연결 시 Supabase에서 직접 확인:

```sql
-- 공유 경유 신규 가입자 추적 (auth 메타데이터에 UTM 저장 시)
SELECT COUNT(*)
FROM auth.users
WHERE raw_app_meta_data->>'utm_campaign' = 'analysis'
  AND created_at >= NOW() - INTERVAL '30 days';
```

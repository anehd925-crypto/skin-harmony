# BeautyLens 마케팅 운영 기획안

> X(구 트위터) 기반 SNS 자동 마케팅 운영 계획

**문서 작성일**: 2026년 4월 15일  
**작성 목적**: BeautyLens 앱의 초기 사용자 획득 및 브랜드 인지도 구축을 위한 SNS 마케팅 운영 방안 제안

---

## 1. 배경 및 목적

### 1.1 배경

- BeautyLens 앱은 주요 기능(AI 전성분 분석, 루틴 궁합 검사, 피부 일기 등) 개발이 완료 단계에 있음
- 앱 출시 후 초기 사용자 유입이 성장의 핵심 변수이나, 별도 마케팅 예산 및 전담 인력이 없는 상황
- 뷰티·스킨케어 관심층은 X(트위터)에서 활발하게 활동하며 제품 정보·성분 정보를 공유하는 경향이 있음

### 1.2 목적

- 소규모 예산으로 지속 가능한 콘텐츠 마케팅 채널 구축
- AI 자동 생성 + 자동 업로드 방식으로 운영 부담 최소화
- 앱의 핵심 가치(성분 분석, 피부 맞춤 추천)를 꾸준히 노출하여 자연 유입 유도

## 3. 마케팅 전략 개요

### 3.1 핵심 전략: 유용한 정보 콘텐츠 + 앱 자연 노출

직접적인 광고보다 **"이런 정보를 주는 계정이구나"** 라는 인식을 쌓아  
팔로워가 자발적으로 공유하고 앱 설치로 이어지도록 유도합니다.

### 3.2 콘텐츠 방향성

```
❌ 피해야 할 방향
- "BeautyLens 앱 설치하세요!" (직접 광고)
- 기능 나열식 홍보 텍스트

✅ 추구할 방향
- "이 성분 조합, 알고 계셨나요?" (정보 제공)
- "이런 피부 타입에는 이 성분이 맞지 않을 수 있어요" (실용 팁)
- "오늘의 주의 성분: XXX" (시리즈 콘텐츠)
```

### 유형 1. 성분 정보 시리즈 (매일)
> 특정 성분의 효능, 주의사항, 어울리는 피부 타입 소개

**예시 포스트:**
```

- 대부분의 피부 타입에 무난

⚠️ 주의할 점  
- 고농도(10% 이상) 사용 시 홍조 가능
- 비타민C와 함께 쓰면 효과가 줄 수 있음

내 피부에 맞는 농도 확인하고 싶다면?
👉 BeautyLens로 무료 분석

#스킨케어 #전성분 #나이아신아마이드 #뷰티성분
```

## 5. 자동 운영 시스템 구성 방안

### 5.1 시스템 개요

```
[콘텐츠 생성 엔진]
   ↓
성분 DB + 피부 정보 + 계절/트렌드 데이터
   ↓
AI(LLM)가 당일 콘텐츠 자동 생성
   ↓
[검수 단계] — 선택 사항: 자동 or 수동 승인
   ↓
X API (MCP) 통해 자동 포스팅
   ↓
포스팅 결과 로그 저장
```

### 5.2 기술 구현 방식

| 구성 요소 | 방법 |
|----------|------|
| **콘텐츠 생성** | Groq(Llama) 또는 OpenAI GPT를 활용한 프롬프트 기반 자동 생성 |
| **스케줄링** | Supabase Cron 또는 별도 서버의 cron job (매일 정해진 시간 실행) |
| **X 포스팅** | X API v2 (MCP 연동) — `POST /2/tweets` 엔드포인트 |
| **콘텐츠 보관** | Supabase DB에 생성된 포스트 기록 저장 |
| **로그 관리** | 포스팅 성공/실패 여부, 조회수, 인게이지먼트 추적 |

### 5.3 일일 포스팅 스케줄 (안)

| 시간 | 콘텐츠 유형 | 이유 |
|------|------------|------|
| 오전 8시 | 오늘의 성분 정보 | 출근·등교 전 SNS 이용 피크 |
| 오후 12시 | 성분 충돌 주의 또는 피부 타입 팁 | 점심 시간 SNS 이용 피크 |
| 오후 9시 | 앱 기능 소개 또는 야간 루틴 팁 | 저녁 여유 시간, 스킨케어 관심 높은 시간대 |

> 초기에는 하루 1~2회로 시작하여 반응에 따라 조정 권장

## 6. 운영 단계별 로드맵

### Phase 1. 준비 단계 (1~2주)

| 작업 | 내용 |
|------|------|

| 작업 | 내용 |
|------|------|

| 수동 인게이지먼트 병행 | 스킨케어 관련 해시태그 게시물에 정보성 댓글 작성 |
| 팔로워 100명 목표 | 뷰티 인플루언서 계정 팔로우, 관련 대화 참여 |
| 반응 데이터 수집 | 어떤 유형의 콘텐츠가 리트윗·좋아요 높은지 분석 |

### Phase 3. 본격 운영 (5주~)

| 작업 | 내용 |
|------|------|
| 하루 2~3회 포스팅으로 확대 | 반응 좋은 콘텐츠 유형 비중 높임 |
| 스레드(Thread) 콘텐츠 도입 | "성분 완전 가이드" 등 심층 정보 시리즈 |
| 앱 기능 업데이트 공지 | 새 기능 출시 시 X를 통해 우선 공지 |
| 마이크로 인플루언서 협업 검토 | 뷰티 성분 관심 계정에 앱 소개 DM 발송 |

## 11. 결론 및 제언

BeautyLens는 성분 분석이라는 명확한 핵심 가치를 보유하고 있으며,  
이는 X에서 정보성 콘텐츠로 자연스럽게 전환이 가능한 강점입니다.

초기 운영은 **수동 검수 + 반자동(콘텐츠 생성 자동, 포스팅 수동 승인)** 방식으로 시작하여  
콘텐츠 품질과 계정 신뢰도를 쌓은 뒤, 완전 자동화로 전환하는 것을 권고합니다.

자동화 마케팅 시스템 구현 여부와 무관하게,  
**X 계정 개설 → 초기 콘텐츠 수동 업로드 → 반응 확인** 순서로  
당장 실행 가능한 것부터 시작하는 것이 현실적입니다.

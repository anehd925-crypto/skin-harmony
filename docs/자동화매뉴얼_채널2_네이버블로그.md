# 채널 2. 네이버 블로그 SEO — 반자동화 세팅 매뉴얼

> AI가 초안을 생성하고, 사람이 검토 후 업로드하는 방식. 포스트 1개 제작 시간 약 25~30분.

**자동화 수준**: ⭐⭐⭐☆☆ 반자동  
**초기 세팅 소요 시간**: 약 1시간 (1회만)  
**이후 포스트 1개 제작 시간**: 25~30분  
**권장 발행 빈도**: 주 2회

---

## 전체 흐름 한눈에 보기

```
① 네이버 블로그 계정·채널 설정 (최초 1회)
  ↓
② 이번 주 공략 키워드 선정 (주 1회, 10분)
  ↓
③ ChatGPT에 프롬프트 입력 → AI가 초안 자동 생성 (1~2분)
  ↓
④ 초안 검토 및 수정 (10~15분)
  ↓
⑤ 네이버 블로그에 업로드 (10~15분)
  ↓
⑥ 월 1회 성과 확인 (블로그 통계 탭, 10분)
```

---

## STEP 1. 네이버 블로그 채널 개설 및 기본 설정

### 1-1. 블로그 개설

1. `blog.naver.com` 접속
2. 상단 "블로그 만들기" 클릭
3. BeautyLens 네이버 계정으로 로그인 (없으면 신규 가입)
4. 블로그 개설 완료

### 1-2. 블로그 기본 정보 설정

**관리 → 기본설정 → 블로그 정보**

| 항목 | 권장 내용 |
|------|---------|
| **블로그 이름** | BeautyLens 뷰티렌즈 공식 블로그 |
| **별명(닉네임)** | BeautyLens |
| **소개글** | AI 전성분 분석 앱 BeautyLens의 공식 블로그입니다. 피부 타입별 성분 정보, 화장품 성분 궁합, 스킨케어 루틴 팁을 매주 연재합니다. |
| **카테고리** | 뷰티/패션 |

### 1-3. 카테고리 설정

**관리 → 메뉴·글·동영상 관리 → 카테고리 관리**

아래 카테고리를 만들어두면 포스팅 정리가 편합니다.

```
📁 성분 정보 시리즈
📁 피부 타입별 가이드
📁 성분 충돌 & 루틴 팁
📁 올리브영 신상 성분 분석
📁 계절별 스킨케어
```

## STEP 2. UTM 추적 링크 만들기

> UTM 링크란 "어디서 왔는지" 추적할 수 있는 특수 링크입니다. 블로그에서 앱으로 몇 명이 왔는지 파악할 수 있습니다.

**블로그에서 쓸 BeautyLens 링크:**

```
기본 링크:
https://beautylens.app?utm_source=naver_blog&utm_medium=organic&utm_campaign=seo_content

카테고리별 링크:
성분 정보 포스트: https://beautylens.app?utm_source=naver_blog&utm_medium=organic&utm_campaign=ingredient_info
피부 타입 포스트: https://beautylens.app?utm_source=naver_blog&utm_medium=organic&utm_campaign=skin_type_tip
올리브영 분석:   https://beautylens.app?utm_source=naver_blog&utm_medium=organic&utm_campaign=oliveyoung
```

이 링크를 포스팅 마무리 부분에 삽입합니다.

## STEP 4. 키워드 선정 방법 (주 1회, 10분)

### 4-1. 네이버 키워드 도구 사용

> 무료로 검색량을 확인할 수 있는 공식 도구입니다.

1. `searchad.naver.com` 접속 (네이버 성과형 디스플레이 광고)
2. 로그인 후 상단 "키워드 도구" 클릭
3. 검색창에 아래 단어를 하나씩 입력해 월간 검색량 확인

**공략 키워드 후보 목록:**

```
[높은 우선순위 — 검색량 있고 경쟁 낮음]
건성 피부 화장품 성분
여드름 피부 성분
임신 중 피해야 할 화장품 성분
레티놀 주의사항
성분 충돌 스킨케어
루틴 성분 순서

[중간 우선순위]
나이아신아마이드 효능
히알루론산 효능
전성분 분석 앱
민감성 피부 성분

[시즌별 키워드 — 해당 월에 발행]
봄철 피부 관리 성분 (3~4월)
여름 선크림 성분 (5~6월)
겨울 건조 피부 성분 (11~12월)
```

### 4-2. 키워드 선정 기준

```
월간 검색량 100 이상 + 경쟁 문서 적은 것 우선
→ 네이버에 그 키워드로 검색했을 때 결과가 적거나 오래된 포스트만 있으면 진입하기 좋음
```

## STEP 5. AI 초안 생성 프롬프트 (복붙용)

> ChatGPT 또는 Claude에 아래 프롬프트 전체를 복붙하고, `[키워드]` 부분만 교체하세요.

### 기본 포스트 생성 프롬프트

```
당신은 뷰티·스킨케어 성분 전문가이자 네이버 블로그 SEO 전문 에디터입니다.

아래 조건에 맞는 네이버 블로그 포스팅을 작성해주세요.

───────────────────────────────────────
[공략 키워드]
{여기에 키워드 입력 — 예: 건성 피부 피해야 할 성분}

[조건]
- 제목: 키워드 포함, 30자 이내, 숫자나 연도 포함 권장 (예: "2026년", "7가지")
- 분량: 1,500자 이상 2,500자 이내
- 구조: 도입부(2~3문장) → 본문(소제목+번호 리스트) → 마무리(앱 연결)
- 말투: 친근하고 읽기 쉬운 블로그 말투 (경어 사용)
- 이미지 설명: "[이미지: ~~~]" 형식으로 어디에 이미지를 넣으면 좋을지 표시
- 가독성: 소제목마다 줄바꿈, 핵심 내용은 굵게(볼드) 처리

[본문에 반드시 포함할 내용]
- 성분명 (한국어+영어 병기)
- 효능 또는 주의사항 (구체적으로)
- 피부 타입별 반응
- 실제 사용 팁

[마무리 문단 — 이 내용으로 끝내주세요]
"내가 쓰는 화장품에 이런 성분이 들어있는지 일일이 찾기 번거롭다면,
BeautyLens(뷰티렌즈)에서 올리브영 제품 URL을 붙여넣거나 성분표를 촬영하면
내 피부 타입 기준으로 바로 분석해드립니다. 무료로 이용할 수 있습니다."

[태그 목록]
포스팅 맨 아래에 관련 태그 20~30개를 "#태그" 형식으로 나열해주세요.
───────────────────────────────────────

포스팅 전체 내용을 바로 출력해주세요.
제목 → 본문 → 태그 순서로 작성해주세요.
```

---

### 시즌별 포스트 생성 프롬프트 (올리브영 신상 분석용)

```
당신은 뷰티·스킨케어 성분 전문가입니다.

올리브영의 이번 달 신상품 성분을 분석하는 네이버 블로그 포스팅을 작성해주세요.

[이번 달 신상품 목록]
(여기에 올리브영에서 직접 확인한 신상품 2~3개 이름을 적어주세요)
예시: "1. 코스RX 달팽이 파워 리페어 크림 2.0, 2. 아누아 청초 수딩 크림"

[조건]
- 제목: "올리브영 {월}월 신상 성분 분석 | 내 피부에 맞는 제품은?"
- 분량: 1,200자 이상
- 각 제품별로: 주요 성분 3가지 소개, 적합한 피부 타입, 주의할 점
- 마무리: 아래 문구 포함
  "각 제품의 성분을 더 자세히 분석하고 싶다면 BeautyLens에서 올리브영 URL을 붙여넣으면 됩니다."
- 태그: 올리브영, 신상, 성분 분석 관련 20개 이상
```

## STEP 6. 블로그 업로드 절차

### 6-1. 포스팅 작성

1. `blog.naver.com` → 상단 "글쓰기" 클릭
2. 제목 입력
3. 본문 붙여넣기
4. **이미지 추가** (SEO에 필수):
   - Canva(`canva.com`) 무료 계정에서 블로그 썸네일 제작
   - 크기: 800×400px 권장
   - 내용: 포스트 제목 + BeautyLens 로고

### 6-2. 발행 설정

| 항목 | 설정값 |
|------|-------|
| 공개 설정 | **전체 공개** |
| 카테고리 | 해당 카테고리 선택 |
| 태그 | AI 생성 태그 복붙 |
| 이웃 공개 | 체크 |
| 검색 허용 | **허용** (기본값 확인) |

### 6-3. URL 삽입

본문 마무리 부분에서 "BeautyLens" 텍스트를 선택하고  
하이퍼링크(`Ctrl+K`)로 UTM 링크 삽입:

```
https://beautylens.app?utm_source=naver_blog&utm_medium=organic&utm_campaign=seo_content
```

## STEP 7. 성과 확인 방법 (월 1회, 10분)

### 블로그 통계 확인

1. 블로그 관리 → "통계" 탭 클릭
2. 확인 항목:

| 지표 | 위치 | 목표 |
|------|------|------|
| 월간 방문자 수 | 방문 분석 | 매월 50% 이상 성장 |
| 포스트별 조회수 | 콘텐츠 분석 → 인기글 | 상위 3개 포스트 조회수 확인 |
| 유입 경로 | 유입 분석 | 검색 유입 비율 70% 이상 |
| 검색어 | 유입 분석 → 검색어 | 어떤 키워드로 들어오는지 확인 |

### 상위 노출 키워드 직접 확인

매월 1회, 아래 키워드를 네이버에서 검색해 내 블로그가 1페이지에 있는지 확인:

```
확인 키워드 목록 (발행한 포스트 기준으로 추가):
- "건성 피부 피해야 할 성분"
- "임신 중 화장품 성분"
- "레티놀 주의사항"
- (이하 발행한 포스트 키워드)
```

## 포스팅 월별 캘린더 (참고용)

| 11~12월 | 겨울 건성 피부 성분, 세라마이드 완전 가이드 |
| 연중 | 임신 중 성분, 여드름 성분, 성분 충돌, 올리브영 신상 분석 |

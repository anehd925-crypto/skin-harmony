# BeautyLens 앱 소개서

> 내 피부에 맞는 성분을 분석해주는 AI 기반 뷰티 앱

---

## 1. 앱 개요

| 항목 | 내용 |
|------|------|
| **앱 이름** | BeautyLens (뷰티렌즈) |
| **한 줄 설명** | 내 피부에 맞는 전성분 분석 앱 |
| **플랫폼** | 웹 앱 (모바일/PC 모두 사용 가능, PWA 지원) |
| **주요 사용자** | 피부 고민이 있는 뷰티 관심층, 성분 민감 소비자, 스킨케어 루틴 관리자 |

## 2. BeautyLens가 해결하는 문제

뷰티 제품을 살 때 이런 경험, 있지 않으신가요?

- "성분표를 보고 싶은데 너무 어렵고 복잡하다"
- "내 피부 타입에 이 제품이 맞는지 모르겠다"
- "알레르기 성분이 들어있는지 직접 찾기가 힘들다"
- "비슷한 제품 두 개 중 어떤 게 나한테 더 좋을지 모르겠다"
- "매일 쓰는 제품들끼리 성분이 충돌하지 않는지 걱정된다"

**BeautyLens는 이 모든 고민을 AI가 자동으로 해결해줍니다.**

---

## 3. 핵심 기능 소개

### 🔍 기능 1. AI 전성분 분석
**"이 성분이 내 피부에 좋은 건가요?"**

- 제품 뒷면 성분표를 사진으로 찍으면, AI가 자동으로 읽고 분석
- 올리브영·쿠팡 제품 URL을 붙여넣으면 자동으로 성분을 가져와 분석
- 성분별 안전도(안전/주의/위험) 등급 표시
- **내 피부 타입에 맞는지** 개인 맞춤 적합도 점수 제공
- 알레르기 유발 성분 자동 감지 및 경고

> 예시: "이 세럼에는 알코올 성분이 포함되어 있어 건성 피부에는 주의가 필요합니다. 당신의 피부 적합도는 72점입니다."

---

### 📸 기능 2. 카메라 스캔 분석
**"사진 한 장으로 끝내는 성분 분석"**

- 스마트폰 카메라로 제품 성분표 촬영
- AI 문자 인식(OCR) 기술로 성분 텍스트 자동 추출
- 촬영 즉시 분석 결과 확인 가능

---

### 📦 기능 3. 제품 탐색 및 비교
**"비슷한 제품, 어느 게 나한테 더 좋을까?"**

- 스킨케어, 선케어, 색조 카테고리별 제품 탐색
- 내 피부 조건 기반 맞춤 추천 점수 제공
- 원하는 제품 2개를 나란히 놓고 성분 비교
  - 공통 성분 / 각 제품에만 있는 성분 구분
  - 안전도·가격·평점 비교

---

### 📅 기능 4. 나만의 스킨케어 루틴 관리
**"아침·낮·저녁 루틴, AI가 점검해드립니다"**

- 아침 / 낮 / 저녁으로 구분된 루틴 설정
- 루틴에 담긴 제품들의 **성분 궁합 검사**
  - 충돌 성분 경고 (예: 레티놀 + 비타민C 동시 사용 주의)
  - 시너지 성분 조합 추천
  - 루틴 점수 및 사용 순서 가이드

---

### 📔 기능 5. 피부 일기
**"내 피부 변화를 기록하고 AI가 분석해드립니다"**

- 캘린더 형태로 매일의 피부 상태 기록
- 피부 점수, 트러블 종류, 메모 작성
- **AI 인사이트**: 일기 3일 이상 작성 시 피부 변화 추세 분석
  - 어떤 날 피부가 좋았는지/나빴는지 패턴 파악
  - 최근 사용 제품과 피부 상태 연관성 분석

---

### 🏷️ 기능 6. 할인 알림 & 찜 기능
**"좋은 제품, 더 싸게 살 때 알려드릴게요"**

- 마음에 드는 제품 찜 등록
- 찜한 제품이 할인될 경우 푸시 알림 발송
- 근처 올리브영 매장 재고 조회 기능

---

### 👥 기능 7. 커뮤니티
**"같은 피부 고민을 가진 사람들과 정보 공유"**

- 성분 분석 결과를 커뮤니티에 바로 공유
- 다른 사용자의 제품 후기·별점·코멘트 확인
- 최신순·인기순 정렬

---

## 4. 사용 흐름 (처음 사용하는 분을 위한 안내)

```
앱 설치
  ↓
회원가입 (구글 계정 또는 이메일)
  ↓
내 피부 정보 입력 (피부 타입, 고민, 민감도, 알레르기 등)
  ↓
홈 화면 — 내 피부에 맞는 제품 추천 확인
  ↓
분석하고 싶은 제품의 URL 또는 성분 사진 촬영
  ↓
AI가 분석 결과 & 내 피부 적합도 제공
  ↓
결과 저장 → 루틴에 추가 → 일기 기록
```

## 5. 내 피부 맞춤화 기준

BeautyLens는 가입 시 아래 정보를 입력받아 **모든 분석과 추천을 개인화**합니다.

| 항목 | 선택 예시 |
|------|----------|
| 연령대 | 10대 / 20대 / 30대 / 40대 이상 |
| 피부 타입 | 건성 / 지성 / 복합성 / 중성 / 민감성 |
| 유수분 상태 | 건조 / 지성 / 복합 |
| 민감도 | 낮음 / 보통 / 높음 |
| 피부 고민 | 여드름 / 색소침착 / 모공 / 주름 / 탄력 / 수분 등 |
| 스킨케어 목표 | 보습 강화 / 미백 / 노화 방지 / 트러블 케어 등 |
| 기피 성분 | 알코올 / 향료 / 파라벤 / 실리콘 등 직접 설정 |
| 특수 상태 | 임신 중 / 모유 수유 중 / 아토피 등 |
| 퍼스널컬러 | 봄웜 / 여름쿨 / 가을웜 / 겨울쿨 |

## 6. 지원 플랫폼 & 기술

- **웹 앱**: 별도 설치 없이 모바일 브라우저에서 바로 사용 가능
- **PWA**: 홈 화면에 추가하면 앱처럼 사용 가능
- **AI 엔진**: Llama 3.3 70B 기반 성분 분석 (Groq)
- **데이터 베이스**: Supabase (실시간 동기화)
- **보안**: Google OAuth, 개인정보 처리방침 제공

## 8. 사용 시나리오 (실제 사용 예시)

### 시나리오 1. 뷰티 쇼핑 전 체크
> "올리브영에서 새로 나온 세럼을 찾았어요. URL을 BeautyLens에 붙여넣으니, '이 제품의 내 피부 적합도는 85점, 단 레티놀 성분이 포함되어 있어 낮에는 사용하지 마세요'라는 안내가 나왔어요."

### 시나리오 2. 화장대 제품 성분 충돌 확인
> "매일 쓰는 토너, 에센스, 크림을 루틴에 등록했더니 'A 토너와 B 에센스의 산 성분이 충돌할 수 있습니다. 저녁에 번갈아 사용하세요'라고 알려줬어요."

### 시나리오 3. 피부 트러블 원인 파악
> "2주 동안 피부 일기를 썼더니 '새 크림 사용 후 트러블이 증가한 패턴이 보입니다. 해당 제품의 향료 성분을 확인해보세요'라는 AI 인사이트가 나왔어요."

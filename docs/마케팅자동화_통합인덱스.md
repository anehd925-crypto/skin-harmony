## 채널별 세팅 순서 요약

### 채널 1. X 자동 포스팅 — 8단계

```
Step 1. X 브랜드 계정 생성
Step 2. X Developer Portal에서 API 키 4개 발급
Step 3. Supabase Secrets에 API 키 등록
Step 4. twitter_post_logs 테이블 생성 (SQL 실행)
Step 5. supabase/functions/post-twitter-content/index.ts 파일 생성
Step 6. supabase/config.toml에 함수 추가
Step 7. Edge Function 배포 (터미널 명령)
Step 8. Cron 스케줄 등록 (SQL 실행)
         → 완료 후 매일 오전 8시 자동 포스팅
```

### 채널 2. 네이버 블로그 — 7단계

```
Step 1. 네이버 블로그 개설 및 프로필 설정
Step 2. UTM 추적 링크 생성
Step 3. AI 초안 생성 도구(ChatGPT) 설정
Step 4. 주 1회 키워드 선정 (네이버 키워드 도구)
Step 5. ChatGPT 프롬프트로 초안 생성 (1~2분)
Step 6. 검토·이미지 추가·업로드 (주 2회)
Step 7. 월 1회 통계 확인
```

### 채널 3. 앱 내 공유 기능 — 6단계

```
Step 1. src/components/ShareResultCard.tsx 파일 생성 (코드 복붙)
Step 2. IngredientAnalysis.tsx에 import 추가
Step 3. 결과 화면에 ShareResultCard 컴포넌트 삽입
Step 4. share_events 테이블 생성 (SQL 실행)
Step 5. npm run build → 배포
Step 6. 월 1회 공유율 SQL 조회로 KPI 확인
```

### 채널 4. 네이버 지식iN — 8단계

```
Step 1. 네이버 브랜드 계정 생성
Step 2. 지식iN 검색 링크 7개 북마크 저장
Step 3. ChatGPT Custom Instructions 설정
Step 4. 답변 프롬프트 4종 메모앱에 저장
Step 5. 매일 15~20분 루틴 실행 시작
Step 6. KPI 스프레드시트 생성
Step 7. 파우더룸 등 커뮤니티 가입
Step 8. 주 1회 채택 수 KPI 기록
```
